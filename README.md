# OSLO. · Business cases

Problemas reais, clientes fictícias.

Este repositório reúne os business cases que a [OSLO.](https://oslostudio.com.br) usa no processo seletivo. Cada case parte de uma pergunta de negócio, traz os números de uma empresa fictícia e pede uma recomendação construída com dados públicos.

Não existe resposta pronta. Queremos ver como você pensa: como estrutura um problema mal definido, onde procura informação, como trata dados imperfeitos e como comunica uma recomendação para quem precisa decidir.

## Como participar

1. Leia o enunciado do case indicado no seu convite.
2. O prazo começa a contar quando você recebe o case por e-mail.
3. Envie a entrega por e-mail para **contato@oslostudio.com.br**.

**Não abra pull request nem publique sua solução** neste repositório ou em outro lugar público. Soluções públicas tiram do case o que ele tem de útil para as próximas pessoas.

## Regras gerais

- Trabalho individual.
- Apenas dados públicos e gratuitos. Toda afirmação numérica com fonte.
- IA é permitida. Conte onde e como usou e como conferiu o resultado.
- Prefira estar certo a estar completo.
